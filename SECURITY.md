# Security policy

Hinglish Typer installs a global keyboard hook (to see the word you are typing) and writes to the clipboard (to insert
Devanagari). It makes no network requests and sends nothing off your machine; learned spellings and phrases are stored
locally in `prefs.json` in the app's user-data folder.

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/anand34577/hinglish-typer/security/advisories/new)
rather than a public issue. Only the latest release is supported.
